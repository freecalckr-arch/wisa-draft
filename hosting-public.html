자주 묻는 질문

MSP가 무엇인가요?

MSP(Managed Service Provider)는 고객이 쓰는 클라우드 인프라를 대신 설계하고 운영하는 관리형 서비스입니다. 클라우드 계정과 사용료는 고객 이름으로 두고, 설계 · 이전 · 모니터링 · 보안 · 비용 관리는 위사가 맡습니다.

이미 쓰고 있는 클라우드 계정도 관리해 주나요?

네. 고객 명의의 기존 AWS · Azure · NAVER Cloud · NHN Cloud 계정에 위사 관리 권한을 연결해 운영합니다. 계정이 없다면 개설부터 함께 진행합니다.

클라우드 요금은 누가 내나요?

서버 · 스토리지 · 트래픽 같은 클라우드 사용료는 고객이 벤더 요금표 기준으로 결제합니다. 위사는 설계 · 이전 · 운영 관리 요금만 따로 청구합니다.

MSP를 해지하면 위약금이 있나요?

위사 MSP는 해지 위약금이 없습니다. 다만 고객이 클라우드 벤더와 직접 맺은 약정(예약 인스턴스 등)은 해당 벤더의 조건을 따릅니다.

프라이빗 클라우드와 무엇이 다른가요?

프라이빗 클라우드는 위사가 직접 구축 · 운영하는 인프라를 월정액으로 쓰는 상품입니다. 퍼블릭 클라우드 MSP는 고객이 고른 AWS · Azure · NAVER Cloud 위에서 위사가 관리를 맡는 방식으로, 이미 클라우드 계약이 있거나 특정 벤더를 써야 할 때 맞습니다.
