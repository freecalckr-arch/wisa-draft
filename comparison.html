현재 쇼핑몰 규모와 향후 비즈니스 로드맵에 따라 맞는 라이선스를 제안해 드립니다.

Cloud

“빠르게 시작하고 운영은 맡기고 싶다면”

  • 초기 비용 없이 쇼핑몰을 바로 열고 싶다
  • 서버 · 보안 · 업데이트를 직접 관리할 인력이 없다
  • 브랜드형 · 입점형 쇼핑몰로 시작한다
  • 콘텐츠 · 글로벌을 정해진 범위에서 도입하고 싶다
  • 첫 창업자
  • 1인 · 소규모 브랜드
  • 성장 중인 전문몰

Enterprise

“우리만의 커머스 시스템을 직접 소유하고 싶다면”

  • 소스코드를 기업의 기술 자산으로 보유해야 한다
  • ERP · POS · WMS 등 내부 시스템과 깊이 연동한다
  • B2B · O2O · 정기배송 · 모바일인앱이 필요하다
  • 보안 정책상 독립 서버 · 전용 DB가 필요하다
  • 중대형 쇼핑몰
  • 웹에이전시 · SI
  • 인하우스 개발팀 보유

부스터 Cloud와 부스터 Enterprise의 차이는 무엇인가요?

부스터 Cloud와 부스터 Enterprise의 핵심 차이는 소유권입니다. 부스터 Cloud는 WISA 클라우드에서 월 단위로 이용하는 구독형 쇼핑몰 솔루션이고, 부스터 Enterprise는 소스코드 라이선스를 구매해 자체 서버에서 운영하는 소유형 솔루션입니다. 그래서 Enterprise는 소스코드 · DB 직접 접근, 전면 커스터마이징, PG사 직접 계약이 가능하고 B2B · O2O · 정기배송 · 모바일인앱까지 모든 쇼핑몰 타입을 지원합니다.

부스터 Cloud와 Enterprise 중 어떤 것을 선택해야 하나요?

아래 조건 중 하나라도 해당하면 부스터 Enterprise를, 해당하지 않으면 부스터 Cloud를 먼저 검토하는 것이 좋습니다.
· 소스코드를 보유하거나 내부 개발팀이 직접 수정해야 한다
· ERP · POS 등 사내 시스템과 깊은 연동이 필요하다
· B2B · O2O · 정기배송 · 모바일인앱 커머스가 필요하다
· 보안 정책상 독립 서버 · 전용 DB가 필요하다
판단이 어렵다면 WISA 상담센터에서 비즈니스 모델을 듣고 추천해 드립니다.

Cloud Hybrid는 Cloud인가요, Enterprise인가요?

Cloud Hybrid는 Cloud 요금제입니다. WISA 클라우드에서 운영되고 자동 업데이트가 그대로 적용되며, 콘텐츠 · 글로벌처럼 세팅이 필요한 기능을 WISA 전담팀이 맞춤 구성해 줍니다. 소스코드와 서버를 직접 다뤄야 한다면 부스터 Enterprise가 맞습니다.

부스터 Cloud와 Enterprise의 비용 구조는 어떻게 다른가요?

부스터 Cloud는 월 이용료(무료~)와 표준 결제 수수료로 운영되어 초기 비용 부담이 적습니다. 부스터 Enterprise는 라이선스(최초 1회)와 구축 · 호스팅 비용이 들지만 월 이용료가 없고, PG사와 직접 계약해 수수료를 협상할 수 있어 거래 규모가 클수록 유리합니다.

부스터 Cloud로 시작해서 나중에 Enterprise로 바꿀 수 있나요?

네. 부스터 Cloud와 부스터 Enterprise는 같은 엔진이라 운영 중인 상품 · 주문 · 회원 데이터를 이전해 이어서 운영할 수 있습니다. Cloud로 작게 시작해 성장 단계에서 Enterprise로 전환할 수 있으며, 전환 일정과 범위는 전담 컨설턴트와 함께 계획합니다.
