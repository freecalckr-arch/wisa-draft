자주 묻는 질문

웹과 DB를 서버 1대에 같이 두어도 괜찮나요?

일정 규모까지는 충분합니다. 다만 서버 1대가 멈추면 쇼핑몰 전체가 멈춥니다. 매출 중단이 곧 손실로 이어지는 규모라면 장애 시 자동 복구되는 프라이빗 클라우드를 함께 검토해 보세요.

기존 S220 · S550 구성은 어떻게 되나요?

기존 이용 고객은 현재 조건이 그대로 유지됩니다. 신규 고객의 다중 서버 구성은 쇼핑몰 규모에 맞춰 견적으로 안내합니다.

전송량을 넘으면 회선이 막히나요?

막히지 않습니다. 월 기본 제공량을 넘은 전송량만 다음 달에 후불로 청구합니다.

서버 관리는 누가 하나요?

방화벽, DDoS 방어, 서버 모니터링은 위사가 기본 제공합니다. 엔터프라이즈 솔루션 설치와 운영 범위는 상담 시 함께 정합니다.
