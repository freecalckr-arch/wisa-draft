모바일 넘기기 (카드 4장)

카드가 4장인 요금제는 모바일(767 이하)에서 세로로 쌓지 않고 한 장씩 옆으로 넘겨 봅니다. 위 라인 탭으로 원하는 요금제로 바로 가고, 넘길 때 같은 항목이 같은 높이에 있어 숫자만 바뀌어 보입니다. PC · 태블릿은 위 목록 규칙 그대로입니다.

뱃지 색

한 카드에 뱃지는 1개. 모양 · 색은 공통 뱃지(태그 · 뱃지 · badge.css)를 그대로 쓰고 요금 카드에서 따로 정하지 않습니다. Cloud = 파랑 · Enterprise = 퍼플은 요금 카드뿐 아니라 모든 페이지의 Cloud · Enterprise 뱃지에 똑같이 씁니다.
