요금 카드

요금제 · 상품 카드는 모든 페이지에서 한 부품(assets/common/plan.css)으로 만듭니다. 기준은 기존 홈페이지 솔루션 > Cloud 요금 카드(.rn-cl-plan) 실측값이고, 페이지마다 다른 것은 카드 개수뿐입니다.

뱃지 색

한 카드에 뱃지는 1개. 색은 상품 계열로 정하고, 같은 페이지 안에서 섞지 않습니다. Cloud = 파랑 · Enterprise = 인디고는 요금 카드뿐 아니라 모든 페이지의 Cloud · Enterprise 뱃지에 똑같이 씁니다 (.pc-pop · .pc-pop.indigo 를 그대로 가져와 씀).

클래스색 (바탕 / 글자)쓰는 곳
.pc-popPrimary 50 / Primary 700 (파랑)Cloud · 구독형 상품 · 일반 상품
.pc-pop.indigoIndigo 50 / Indigo 700Enterprise · 라이선스 소유형
.pc-pop.grayGray 100 / Gray 700분류만 알리는 뱃지 (강조 없음)
