개발 검수

개발을 마친 뒤 개발자가 스스로 시안과 맞는지 확인하는 순서입니다. 대부분은 자동 점검이 찾고(글자 · 크기 · 모양 · 애니메이션 시간 · 호버 · 동작 줄이기 · 가로 넘침 · 깨진 이미지 등), 사람이 직접 봐야 하는 터치 · 키보드 · 움직임 순서만 질문 리스트로 확인합니다.

순서

  1. 자동 점검 · 해상도 4개구현한 페이지마다 1440 · 1100 · 820 · 390 에서 자동 점검을 돌려 나온 항목을 고칩니다. 0개가 될 때까지 반복합니다. 경계 폭(아래 표)에서도 한 번씩 돌려 기본 확인(가로 넘침 · 깨진 이미지 등)을 0개로 만듭니다.
  2. 질문 리스트질문 리스트를 페이지별로 체크합니다. 자동 점검이 못 보는 터치 · 키보드 · 움직임 순서만 남겼습니다.
  3. 시안과 나란히 보기시안 HTML 과 구현 페이지를 같은 폭 창 두 개로 띄워 위에서 아래로 같이 내려 봅니다. 다른 곳은 캡처해 표시합니다.
  4. 결과 전달개발이 끝나면 디자이너에게 알려 주세요. 디자이너가 검수를 진행합니다. 개발 중에 디자인 수정이 필요한 부분이 생기면 페이지 · 해상도 · 영역 · 캡처를 적어 디자이너에게 먼저 공유해 주세요.

시안 페이지에서 미리 잰 값(docs/assets/qa/spec-페이지.js)과 구현 페이지를 그 자리에서 재서 비교합니다. 영역(#geo-hero ~ #cta · 호스팅은 #host-table · #host-incl · #host-calc 포함) 안 모든 요소가 대상입니다. 기본 확인은 시안 값 없이 페이지 전체를 봅니다.

쓰는 법

  1. 파일 두 개 연결전달 폴더의 docs/assets/qa/ 를 개발 서버에 잠시 올리고, 구현한 페이지 맨 아래에 두 줄을 넣습니다 (검수가 끝나면 지웁니다).
  2. 폭 맞추기개발자 도구 기기 툴바에서 폭을 1440 · 1100 · 820 · 390 중 하나로 정확히 맞춥니다 (경계 폭이면 기본 확인만). 기기의 '동작 줄이기'는 끕니다.
  3. 실행콘솔에서 await WISAqa("geo-price") (페이지 이름) 를 실행합니다. 맨 위에서 7초 지켜본 뒤 페이지를 끝까지 천천히 내리며 재므로 20~40초 동안 화면을 건드리지 않습니다.
  4. 결과 보기화면 오른쪽 결과 창에 항목별로 다른 곳이 나옵니다. 항목을 누르면 그 요소로 이동해 빨간 테두리로 표시합니다. 같은 결과가 콘솔에도 남습니다.

결과 읽는 법

표시뜻 · 할 일
기본 확인가로 넘침은 화면 밖으로 나간 가장 바깥 요소를 표시합니다 (누를 때마다 다음 요소). 깨진 이미지는 경로 · 파일 이름을, 시안 전용 코드는 지울 곳을 알려 줍니다.
문구 다름"시안 문구 → 구현 문구" 로 나옵니다. 버튼 · 제목 글자를 시안 최신 문구로 바꿉니다.
visibility hidden요소 자리는 있는데 보이지 않습니다. 기존 홈페이지 CSS 에 같은 이름의 클래스(예: .ani)가 있는지 확인하고, 겹치면 클래스 이름을 바꿉니다.
위 영역과 사이 간격앞 영역의 아래 여백(padding-bottom · margin-bottom)과 이 영역의 위 여백을 확인합니다 (예: FAQ 아래 여백 0 + CTA 위 여백).
시안에 있는데 없는 요소마크업이 빠졌거나 클래스 이름이 바뀜. 요소는 "영역 id + 태그 + 클래스 + 같은 이름 중 몇 번째"로 짝을 짓습니다. 기존 홈페이지 구조에 맞춰 클래스 이름을 바꿨다면 그 요소는 여기 나오므로, 바꾼 곳은 시안과 나란히 놓고 눈으로 확인합니다.
글자 · 모양 · 크기"시안 값 → 구현 값" 으로 나옵니다. 페이지 <style> 일부가 빠졌거나 공통 파일 순서가 다를 때 주로 생깁니다.
애니메이션 · 스크립트 움직임 없음페이지 아래쪽 <script> 의 해당 @region 이 빠졌거나, 스크립트가 찾는 클래스 · id 가 바뀐 경우입니다.
스크립트 움직임만 1~2개컴퓨터가 바쁘면 타이머가 늦게 돌아 한두 개가 잘못 나올 수 있습니다. 다른 창을 닫고 한 번 더 돌려 같은 항목이 다시 나오면 고칩니다.
시간 · 간격 다름애니메이션 시간 · 지연 · 반복이나 키워드 교체 · 자동 넘김 타이머 값이 시안과 다릅니다. 영역마다 시간이 정해져 있습니다 (인터랙션 목록).
동작 줄이기 규칙 없음@media (prefers-reduced-motion: reduce) 블록이 빠졌습니다. 이 설정을 켠 기기에서 반복 움직임이 멈추지 않습니다.
호버 없음호버 규칙(:hover)이 빠졌습니다. 마우스가 있는 기기 전용(@media (hover: hover))인 규칙도 있습니다.
회색 글씨 항목시안에서도 계속 움직이는 요소(키워드 교체 · 자동 탭 · 반복 애니메이션 안쪽)라 재는 순간에 따라 값이 다를 수 있습니다. 눈으로 한 번 확인만 합니다.
채팅 · 타이핑 화면말풍선 · 글자가 생겼다 사라지는 화면(리포트 AI 대화 · 히어로 대기 목록 등)은 시안끼리 비교해도 1~4개 차이가 남을 수 있습니다. 해당 화면 항목만 나오면 눈으로 움직임을 확인하고 넘어갑니다.
시안에 없는 요소 (참고)구현에만 있는 요소 수입니다. 감싸는 태그를 더한 정도면 괜찮습니다.

헤더 · GNB · 푸터는 기존 홈페이지 것을 쓰므로 비교하지 않습니다. 시안 전용 코드(시안 히스토리 #vh)도 제외됩니다.
