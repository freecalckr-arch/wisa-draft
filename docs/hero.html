영역 규격

히어로

히어로는 페이지 묶음(마케팅 · 솔루션 · 메인 등)마다 형태가 다릅니다. 묶음별로 탭을 나눠 박스 규격을 정하고, 안의 구성은 그 박스에 맞춥니다.

GEO · 온사이트마케팅 등 자사몰 마케팅 페이지 히어로입니다. 안의 구성(폰 · 카드 · 채팅 등)은 페이지마다 다르게 만들고, 규격은 파란 박스(.sh-visual) 하나만 고정합니다.

배치 규칙

  1. 안의 구성은 박스 바닥에 붙인다넘치는 부분은 박스가 잘라냅니다 (overflow: hidden).
  2. PC 최소(1024~1439)는 PC 1440 구성을 그대로 줄인다1440 화면의 박스(1340×460)와 안의 창 · 카드 · 이미지 전체를 한 장으로 보고 s = min(1, 칸 폭 ÷ 1340) 배로 같이 줄입니다. 해상도마다 카드를 숨기거나 위치 · 크기를 바꾸지 않습니다 (공통 wisa.css · wisa.js hero-fit).
  3. 태블릿 · 모바일은 박스 양옆 떠 있는 카드를 숨긴다공간이 부족해 겹치기 때문입니다. 필요한 정보는 박스 안 구성으로 옮깁니다.
  4. 히어로에는 그래프를 넣지 않는다그래프는 그래프 영역(#geo-market)에서만 씁니다.
  5. 떠 있는 카드 움직임은 GEO 와 같게위아래로 천천히 (shFloat 6s ease-in-out infinite alternate), 좌우 카드는 반 박자 어긋나게 (-3s).

.sh-visual { height: 460px; margin-inline: 50px; border-radius: 24px; padding-top: 40px; overflow: hidden; }
@media (min-width: 1024px) and (max-width: 1439px) { #geo-hero .sh-visual { width: 1340px; height: 460px; zoom: var(--hz); } }   /* --hz = min(1, 칸 폭 ÷ 1340) · wisa.js hero-fit */
@media (max-width: 1023px) { .sh-visual { height: 440px; } }
@media (max-width: 767px)  { .sh-visual { margin-inline: 0; border-radius: 0; padding: 40px 40px 0; } }

솔루션 페이지 히어로

준비 중입니다. 솔루션 페이지 시안을 정리할 때 히어로 박스 크기 (구간별 가로 · 세로 · 여백 · 모서리)를 이 탭에 표로 추가합니다.

메인 페이지 히어로

준비 중입니다. 메인 페이지 시안을 정리할 때 히어로 크기를 이 탭에 표로 추가합니다.

탭 추가 · 작성 기준

  • 새 묶음(예: 호스팅)은 <section class="panel" data-tab="이름"> 하나를 추가하면 탭이 생깁니다.
  • 구간(PC · PC 최소 · 태블릿 · 모바일)별 가로 · 세로 · 바깥 여백 · 모서리 · 안쪽 여백을 표로 적고, 크기 · 여백은 10 단위로 끝냅니다.
