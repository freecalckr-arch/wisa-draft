영역 규격

히어로

히어로 안의 구성(폰 · 카드 · 채팅 등)은 페이지마다 다르게 만듭니다. 규격은 파란 박스(.sh-visual) 하나만 고정하고, 안의 구성은 이 박스에 맞춥니다.

구간박스 가로박스 세로좌우 바깥 여백모서리안쪽 위 여백

배치 규칙

  1. 안의 구성은 박스 바닥에 붙인다넘치는 부분은 박스가 잘라냅니다 (overflow: hidden).
  2. 태블릿 · 모바일은 박스 양옆 떠 있는 카드를 숨긴다공간이 부족해 겹치기 때문입니다. 필요한 정보는 박스 안 구성으로 옮깁니다.
  3. 히어로에는 그래프를 넣지 않는다그래프는 그래프 영역(#geo-market)에서만 씁니다.
  4. 떠 있는 카드 움직임은 GEO 와 같게위아래로 천천히 (shFloat 6s ease-in-out infinite alternate), 좌우 카드는 반 박자 어긋나게 (-3s).

.sh-visual { height: 460px; margin-inline: 50px; border-radius: 24px; padding-top: 40px; overflow: hidden; }
@media (max-width: 1023px) { .sh-visual { height: 444px; } }
