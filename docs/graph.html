그래프

마케팅 시안 그래프는 8가지 양식 중에서 데이터에 맞는 것을 골라 씁니다. 그래프 영역(#geo-market) 메인 그래프 3종은 SVG 규격, 화면 이미지 안 작은 그래프 5종은 공통 부품(chart.css)입니다.

데이터에 맞는 그래프 고르기

그래프는 아래 8가지 중에서만 고릅니다. 같은 성격의 데이터면 같은 그래프를 쓰고, 한 화면에 그래프는 1개입니다.

모든 그래프 공통

  1. 색은 그레이 + 블루 1개기본 계열 Gray 300, 봐야 할 값 1개만 Primary 600. 비교 대상은 Gray 400. 계열이 여러 개면 Gray 명도(200 · 300 · 400)로 나눕니다.
  2. 이슈 · 증감 색이슈(이상 · 손해)는 Error 600 레드 화면당 1곳. 증감은 방향 색 — 증가 ▲ Error 600 · 감소 ▼ Primary 600.
  3. 실선 = 실제 · 점선 = 가정 · 전망실제 데이터는 실선, 예측이나 "하지 않을 때" 같은 가정 계열은 점선입니다.
  4. 양은 적게막대 · 행 3~5개(세로 막대는 8개까지). 수치 표시는 강조 값과 끝 값 위주로.
  5. 움직임 1번화면에 들어오면 선은 왼쪽부터 그려지고 막대 · 도넛은 차오릅니다. 동작 줄이기 설정이면 바로 보입니다.

그래프 영역 양식 3가지

그래프 영역(#geo-market) 메인 그래프는 아래 3가지 양식 중 하나를 씁니다. 같은 양식을 쓰는 페이지는 하나만 실제 페이지에서 그대로 불러와 보여 주고, 나머지는 링크로 둡니다. 새 페이지는 데이터 성격에 맞는 양식을 골라 같은 모양으로 그립니다.

해상도

그래프는 화면에 들어오면 한 번 그려집니다. 다시 보려면 해상도 버튼을 누릅니다.

화면 이미지 안 그래프 부품

화면 이미지(창) 안 작은 그래프는 공통 부품을 그대로 가져다 쓰고, 데이터 값 --v(0~1)와 글자만 바꿉니다. 페이지에 assets/common/chart.css · chart.js 가 연결돼 있어야 합니다 (마케팅 시안은 모두 연결됨). gx-anim 을 붙이면 화면에 들어올 때 차오릅니다.
