전달할 때마다 한 줄씩 추가합니다. 바뀐 내용의 자세한 기록은 각 페이지 HTML 맨 위 [개발 전달] 주석에 있습니다.

여는 법

  1. 폴더 받기드라이브의 전달 폴더를 통째로 내려받아 압축을 풉니다. 폴더 안 상대 경로로 연결되어 있으니 파일 위치를 바꾸지 않습니다.
  2. 규칙 사이트 열기docs/index.html 을 브라우저로 엽니다. 프로젝트 안내의 보는 순서대로 확인합니다.
  3. 시안 열기index.html(시안 목록) 또는 페이지 HTML 을 브라우저로 엽니다. 브라우저 폭을 줄이면 해상도별 화면을 볼 수 있습니다.
