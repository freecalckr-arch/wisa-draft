아티팩트는 확인용 사본입니다. 아티팩트에서 고친 내용은 사이트에 반영되지 않으니, 수정은 저장소 파일에서 합니다.

작업 순서

  1. 받기처음 한 번 git clone https://github.com/freecalckr-arch/wisa-draft.git, 이후에는 작업 전마다 git pull
  2. 고치기해당 페이지 HTML 을 고치고, 이 사이트의 규칙을 따릅니다.
  3. 기록HTML 맨 위 [개발 전달] 주석과 바뀐 CSS 의 patch-NNN 주석에 수정 내용을 남깁니다.
  4. 확인1440 · 1100 · 820 · 390 에서 보고, 모바일에서 페이지가 옆으로 밀리지 않는지 봅니다.
  5. 올리기git add → git commit → git push. 1~2분 뒤 시안 보기 주소에 반영됩니다.

시안 히스토리

각 시안 왼쪽 아래 "시안 히스토리"(#vh 의 data-items)에 지난 차수 링크를 남깁니다. 지난 링크는 지우지 않고, 새 차수를 만들면 한 줄 추가합니다.

{"date":"2026.11.07","name":"GEO · 반응형 시안 · 해결 영역 규격","current":true}

마지막 수정 2026-11-07 · 규칙이 바뀌면 이 페이지를 먼저 고치고, 각 시안 HTML 맨 위 [개발 전달] 주석도 같이 맞춥니다.
