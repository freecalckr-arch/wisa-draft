영역 이름

같은 묶음의 페이지는 같은 순서와 이름으로 영역을 부릅니다. 페이지 묶음(마케팅 · 호스팅 등)마다 탭으로 나눠 정리합니다.

GEO · 온사이트마케팅 등 자사몰 마케팅 페이지에 씁니다. 코드 id 는 GEO 에서 시작한 이름을 그대로 씁니다.

영역 (흐름 순서)

단계는 페이지에 따라 두 가지 타입 중 하나를 씁니다. 둘 다 같은 이름 · 같은 id 입니다.

부속 영역

일부 페이지에만 있는 영역입니다. 흐름 순서 번호 없이, 있으면 그대로 씁니다.

영역코드 id쓰는 페이지위치
URL#geo-scopeGEO단계와 해결 사이 · 해결과 한 패널로 이어짐 (쇼핑몰 URL 입력)
다짐 띠#geo-vowGEO · 온사이트 (지금은 숨김)해결과 리포트 사이

요청이나 피드백에서 영역을 말할 때도 이 이름을 씁니다. 예: "단계 영역 3번 탭 이미지", "그래프 영역 모바일".

호스팅 페이지 영역

준비 중입니다. 호스팅 페이지 시안을 시작할 때 흐름 순서대로 영역 이름과 코드 id 를 정해 이 탭에 표로 추가합니다.

정할 때 지킬 것

  • 마케팅 탭과 같은 역할의 영역은 같은 이름을 씁니다 (예: 히어로 · CTA).
  • 코드 id 는 페이지 묶음 접두어로 시작합니다 (예: #host-…).
  • 이미지 · 그래프 크기는 이미지 · 그래프 규칙을 그대로 따르고, 새 영역의 PC 기준 크기는 이미지 페이지 표에 추가합니다.
