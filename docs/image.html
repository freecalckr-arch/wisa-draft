영역 규격

이미지

문제 · 단계 · 해결의 화면 이미지와, 앞으로 추가하는 모든 화면 이미지에 적용합니다. PC 크기로 한 번만 그리고 화면이 좁아지면 비율 그대로 줄입니다.

축소 규칙

  1. PC 크기로 한 번만 그린다영역마다 PC 기준 크기(가로 × 세로)를 정하고 그 크기로 만듭니다. 기준 크기는 10 단위로 끝냅니다 (551 → 550). 레이아웃에서 나오는 크기면 안쪽 여백 · 간격을 10 단위로 맞춰 크기가 10 단위로 떨어지게 합니다.
  2. 화면이 좁아지면 비율 그대로 줄인다레이아웃을 다시 짜거나(줄바꿈 · 칸 수 줄이기), 가로만 늘이거나 줄이지 않습니다.
  3. 확대하지 않는다이미지 칸이 PC 가로보다 넓으면 PC 크기 그대로 가운데에 둡니다 (태블릿).
  4. 이미지 안 글씨도 같은 배율로 작아진다글씨만 따로 키우지 않습니다.

배율

s = min(1, 이미지 칸 폭 ÷ PC 가로) → 노출 크기 = PC 가로 × s · PC 세로 × s

예: 단계 · 탭 타입 이미지 (PC 560 × 480)

CSS

이미지 칸(예: .vis) 안에 PC 크기 이미지(예: .win)를 그리고, 스크립트가 칸 폭으로 배율 --s 를 계산합니다.

/* 1439 이하: PC 크기로 그리고 배율 --s 로 축소 · 칸이 넓으면 PC 크기로 가운데 */
@media (max-width: 1439px) {
  .vis { position: relative; overflow: visible; height: calc(PC세로px * var(--s, 1)); }
  .vis > .win { width: PC가로px; height: PC세로px; max-width: none; margin-inline: auto;
    transform-origin: 0 0; transform: scale(var(--s, 1)); }
}

스크립트

숨겨져 있던 탭이 열릴 때도 다시 계산되도록 ResizeObserver 를 씁니다.

// [이미지 칸 선택자, PC 가로]
const list = [['#geo-why .bt-vis', 550], ['#geo-how .jt-panel .sc', 560], ['#geo-diagnosis .sr-vis', 460]];
const ro = new ResizeObserver(es => es.forEach(e => {
  const v = e.target;
  if (v.clientWidth) v.style.setProperty('--s', Math.min(1, v.clientWidth / v.dataset.pcw).toFixed(4));
}));
list.forEach(([sel, w]) => document.querySelectorAll(sel).forEach(v => { v.dataset.pcw = w; ro.observe(v); }));
