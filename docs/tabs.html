탭

탭은 네 가지입니다. 히어로 위에서 같은 묶음의 페이지를 오가는 페이지 전환 탭, 단계 영역(#geo-how)에서 단계마다 화면을 바꾸는 단계 탭, 같은 영역 안에서 보는 내용만 바꾸는 라인 탭, 값을 고르는 세그먼트 탭(요금 계산 결제 방식 등)입니다. 페이지 전환 탭(회색 알약)은 다른 페이지로 이동할 때만 쓰고, 한 영역 안 전환에는 쓰지 않습니다.
