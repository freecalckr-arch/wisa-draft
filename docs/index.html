개요

WISA 마케팅 페이지 리뉴얼 시안을 구현할 때 보는 규격입니다. 왼쪽 메뉴의 개발 전달이 구현 대상이고, 시안 작업은 시안을 그릴 때만 쓰는 규칙이라 구현하지 않아도 됩니다.

보는 순서

  1. 기존 수정 목록신규 시안에 맞춰 기존 홈페이지 소스도 고쳐야 하는 항목입니다 (CTA 빛 위치 · 페이지 전환 탭 · 모바일 타이틀). 기존 수정 목록
  2. 기초해상도 구간 · 영역 이름 · 그리드 · 컬러 · 타이포. 모든 페이지가 같이 씁니다.
  3. 영역 규격히어로 · 이미지 · 그래프의 크기와 해상도별 축소 규칙입니다.
  4. 페이지 시안위 규칙이 적용된 완성 시안입니다. 각 HTML 맨 위 [개발 전달] 주석에 수정 기록이 있습니다.

컴포넌트(탭 · 카드 · CTA)와 인터랙션 목록은 고객 피드백 반영 후 채웁니다.

공통 파일은 페이지마다 wisa.css?v=수정 번호 처럼 같은 숫자를 붙여 불러옵니다. 페이지 HTML 의 <style> 이 공통 파일보다 뒤에 오므로 페이지 전용 규칙이 공통 규칙을 덮어씁니다.

수정 기록 보는 법

  1. [개발 전달] 주석각 페이지 HTML 맨 위에 날짜 · 수정 번호(patch-NNN) · 수정 내용이 최신순으로 있습니다.
  2. patch 주석CSS · 스크립트 안의 patch-NNN 주석으로 해당 코드를 찾을 수 있습니다. 공통 파일은 @region 이름 단위로 나뉘어 있습니다.
