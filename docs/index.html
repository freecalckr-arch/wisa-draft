프로젝트 안내

WISA 홈페이지에 새로 추가하는 마케팅 서브페이지(자사몰 마케팅 · 채널마케팅)의 구현 규격입니다. 신규 페이지 스타일에 맞춰 기존 홈페이지의 공통 요소도 일부 수정합니다.

모든 신규 페이지는 같은 공통 파일(assets/common/wisa.css · wisa.js)과 같은 영역 구성(히어로 → 문제 → 그래프 → 단계 → 해결 → 리포트 → 사례 → FAQ → CTA)을 씁니다. 해상도는 PC · PC 최소 · 태블릿 · 모바일 네 구간입니다.

보는 순서

  1. 기존 수정 목록신규 시안에 맞춰 기존 홈페이지 소스도 고쳐야 하는 항목입니다 (CTA 빛 위치 · 페이지 전환 탭 · 모바일 타이틀 · 탑버튼). 기존 수정 목록
  2. 공통 규격해상도 구간 · 영역 이름 · 그리드 · 컬러 · 타이포. 모든 페이지가 같이 씁니다.
  3. 영역 규격히어로 · 이미지 · 그래프의 크기와 해상도별 축소 규칙입니다.
  4. 페이지 시안위 규칙이 적용된 완성 시안입니다. 각 HTML 맨 위 [개발 전달] 주석에 수정 기록이 있습니다.

컴포넌트(탭 · 카드 · CTA)와 인터랙션 목록은 고객 피드백 반영 후 채웁니다.
