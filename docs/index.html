모바일 포커스 인터랙션

모바일(≤767)에서는 마우스가 없어서, 핵심 차이 · 상세 기능 비교 표를 스크롤하면 화면 가운데에 온 항목 하나가 켜집니다. 두 표는 같은 방식 · 같은 색을 씁니다.

  1. 켜지는 항목화면 세로 가운데에 가장 가까운 항목 1개만 켜짐 (.on). 스크롤할 때마다 다시 계산합니다 (한 프레임에 1번 · requestAnimationFrame).
  2. 모두 꺼지는 때표가 화면 위쪽 25% 위로 지나갔거나, 아래쪽 75% 아래에 아직 있을 때. 표 묶음 제목 줄(tr.g)은 켜지지 않습니다.
  3. 켜진 모습항목 이름 띠 Primary 50 바탕 / Primary 700 글자 + 항목 전체(띠 + 두 값)에 Primary 600 선 1.5. 선은 위에 덮는 선(::after · inset)이라 레이아웃이 움직이지 않습니다. 켜지고 꺼질 때 0.3초 페이드.
  4. 모서리선은 항목 모서리를 따라갑니다. 핵심 차이 마지막 항목은 표 둥근 모서리에 맞춰 아래 모서리 15 (표 모서리 16 − 테두리 1).
  5. 동작 줄이기기기에서 동작 줄이기(prefers-reduced-motion)를 켜면 아무것도 켜지지 않습니다.
