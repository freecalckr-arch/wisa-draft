개요

WISA 페이지 시안이 함께 쓰는 규칙입니다. 화면 이미지는 PC 크기로 한 번 그리고, 화면이 좁아지면 비율 그대로 줄입니다.

시안 완료 전 체크리스트

  • 영역 id 가 영역 이름 표의 이름 · 순서와 맞는다
  • 히어로 파란 박스가 PC · PC 최소 460, 태블릿 · 모바일 444 이고 가로 규격을 지킨다
  • 화면 이미지가 PC 크기로 그려지고, 1439 이하에서 비율 그대로 줄어든다 (가로만 바뀌지 않는다)
  • 태블릿에서 이미지가 PC 크기보다 커지지 않는다
  • 그래프 영역 그래프 세로가 태블릿 220 · 모바일 210 이다
  • 1440 · 1100 · 820 · 390 에서 확인했고, 모바일 390 · 360 에서 페이지가 옆으로 밀리지 않는다

규격 페이지 추가하기

  1. docs/ 에 있는 페이지 하나를 복사해 새 이름으로 저장합니다 (예: docs/tab.html).
  2. 제목 · 설명 · 본문을 고칩니다. 탭이 필요하면 <section class="panel" data-tab="이름"> 으로 나눕니다.
  3. docs/assets/docs.js 맨 위 NAV 에서 해당 메뉴의 null 을 파일 이름으로 바꾸거나 새 줄을 추가합니다.
